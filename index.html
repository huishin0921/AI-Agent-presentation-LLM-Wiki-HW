AI Agents

智慧代理人的基礎與應用

從「對話機器人」到「能辦事的數位助手」

向右滑動開始 👉

1. 什麼是 AI Agent？

AI Agent 是一個以大型語言模型 (LLM) 為大腦的系統。

  • 不僅能像 ChatGPT 一樣跟你對話。
  • 更能理解目標、自主拆解任務。
  • 能夠在虛擬環境中採取行動來達成目的。

2. 核心架構

一個完整的 Agent 通常包含三個核心要素：

  • 大腦 (Brain)：負責思考、推理與規劃 (LLM)。
  • 感知 (Perception)：接收指令與理解環境狀態。
  • 行動 (Action)：呼叫工具執行任務。

3. 思考與規劃 (Planning)

  • 利用思維鏈 (Chain of Thought) 拆解複雜任務。
  • 面對龐大的問題，它會將其切分成多個小步驟 (A → B → C)。
  • 具備自我反思 (Reflection) 與修正錯誤的能力。

4. 記憶機制 (Memory)

為了不「過目即忘」，Agent 具備兩種記憶：

  • 短期記憶：記住當下的對話上下文，處理眼前任務。
  • 長期記憶：透過外部資料庫 (如 LLM Wiki)，隨時檢索過去的知識與經驗。

5. 使用工具 (Tools)

Agent 最強大的能力在於「長出了手腳」。

  • 突破 LLM 無法連網或計算的限制。
  • 主動呼叫 API 進行：網路搜尋、讀取本地檔案。
  • 甚至能自動寫 Python 程式碼並執行出結果。

6. 控制流程 (Loop / Graph)

  • Agent 不只是一直線執行，而是具備迴圈 (Loop) 概念。
  • ReAct 模式：思考 (Reason) ➔ 行動 (Act) ➔ 觀察 (Observe) ➔ 重新思考。
  • 如果發生錯誤，它會退回上一步自我修正。

7. 實際應用案例

專屬的「課堂 PPT 整理系統」

  • 取得資料：自動讀取上課簡報與 PDF。
  • 整理重點：透過 Agent 大腦濃縮關鍵字。
  • 產生結果：自動排版成極簡網頁，大幅節省複習時間。

8. 總結

AI Agent 讓 AI 從「回答問題的百科全書」，進化成「自動解決問題的虛擬員工」。
